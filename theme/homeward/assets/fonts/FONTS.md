# Local font sources

All font files below are bundled in this directory, downloaded on 2026-11-01 from the Fontsource packages on jsDelivr. No font is fetched from a third party at runtime.

All twelve families use SIL Open Font License 1.1. Each family has its own OFL file in this directory, including its upstream copyright notice. Licence sources are listed below.

Static Latin files use the requested @fontsource npm packages through jsDelivr. Variable fonts are published separately by Fontsource as @fontsource-variable; these cover a continuous weight range and are preferred when installed. Static faces remain as fallback. See https://fontsource.org/docs/getting-started/variable for the package split.

Download each URL to the filename in the first column inside this directory. Keep the OFL files with the fonts. URLs are unpinned; pin versions and record checksums when preparing a release.

## Notes

- DM Serif Display is published in one weight (400) and an italic only, so it has no 600, 700 or variable file.
- Its upstream OFL.txt names Adobe (Source) as copyright holder, and is kept exactly as downloaded.
- Atkinson Hyperlegible has no variable file and no 600 weight upstream.
- The plugin ships a small preview subset in `plugin/homeward-rescue/assets/fonts/` (the variable file for each font that has one, otherwise the 400 and 700 files, plus every OFL file) so the setup wizard preview shows real fonts even before this theme is installed. The shared font list lives in `plugin/homeward-rescue/includes/class-fonts.php`.
