A free block theme for animal rescues. It works with the Homeward Rescue plugin.

== Description ==

Homeward is a simple, readable block theme made for small animal rescues. Your
rescue's name, logo, colours and fonts replace the placeholder name everywhere
visitors can see. Everything is editable in the Site Editor.

The theme includes ready-made patterns for the home page: hero, mission,
animals, how to adopt, foster and volunteer cards, stories, testimonials,
events, ways to give, and contact. All sample wording is fictional and clearly
marked, so replace it with your own.

Animals, adoption stories, events, the donate panel and the contact form come
from the Homeward Rescue plugin. If the plugin is not active, those blocks show
a short message instead of breaking the page, and administrators see a notice
they can dismiss. The theme never installs anything for you.

== Installation ==

1. Install and activate the Homeward Rescue plugin first, then open its setup
   wizard. The wizard can turn this theme on for you.
2. Or go to Appearance > Themes > Add New > Upload Theme, choose homeward.zip,
   install it and activate it.
3. Open Appearance > Editor to change the site title, logo, menu and patterns.

The theme does not create pages, change site options or import images. The
plugin's wizard does that, if you ask it to.

== Fonts ==

Twelve font families are bundled and served from your own site, so visitors'
browsers never contact Google. Serif: Fraunces, Lora, Source Serif 4, Playfair
Display, DM Serif Display, Merriweather. Sans serif: Inter, Atkinson
Hyperlegible, Nunito Sans, Figtree, Work Sans, Nunito. Fraunces (headings) and
Inter (text) are the defaults. Choose others in the plugin's setup wizard.

== Accessibility ==

Every template has a main landmark and a skip link. Focus outlines are visible,
controls are easy to tap, and layouts adapt to small screens. The default text
and button colours meet WCAG AA contrast. If you change colours, check that
text stays readable. Animation is switched off when a visitor asks for reduced
motion.
